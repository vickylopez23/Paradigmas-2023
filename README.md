# Paradigmas de Programación — FaMAF (UNC) 2023

Laboratorios de la materia **Paradigmas de Programación** de la Licenciatura en Ciencias de la Computación (FaMAF, UNC), 2023. Cada laboratorio trabaja un paradigma distinto.

**Grupo 12:** 

| Lab | Paradigma | Qué hicimos | Lenguaje |
|-----|-----------|-------------|----------|
| [Lab 1](lab1) | Funcional | Un lenguaje (DSL) para describir dibujos y su interpretación gráfica, con la que se arma el cuadro de Escher | Haskell + Gloss |
| [Lab 2](lab2) | Orientado a objetos | Lector de feeds RSS y Reddit con detección y clasificación de entidades nombradas | Java |
| [Lab 3](lab3) | Distribuido | El lector de feeds sobre Apache Spark, con un índice invertido para buscar artículos por entidad | Java + Spark |

Cada carpeta tiene su README con cómo correrlo, y un `INFORME.md` con el informe que entregamos, que incluye las respuestas a las preguntas de la consigna.
